🎵 Spotify Clone

A responsive and interactive **Spotify Clone** built using **HTML, CSS, and JavaScript**.

This project recreates the look and basic functionality of a music player, with a clean UI/UX design and interactive controls. Songs are loaded into the project and can be played directly through the web interface.

## 🚀 Features

- ▶️ Play / Pause songs
- ⏭️ Next song
- ⏮️ Previous song
- 📊 Seek / Progress bar
- 🔊 Volume control
- 🎵 Song details display
- 🎶 Multiple songs available for playback
- 🖱️ Interactive music player controls
- 🎨 Clean and user-friendly UI/UX
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and UI/UX design
- **JavaScript** – Music player functionality and interactivity
